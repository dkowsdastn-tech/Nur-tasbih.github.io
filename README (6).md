# Nur PWA

Мобильное исламское приложение: тасбих с локальным сохранением, скретч-карты, карточки пользы, бережный справочный помощник, аудио Корана, истории сообщества и ручная модерация.

## Запуск

Не открывайте `index.html` двойным щелчком: режим `file://` не позволяет браузеру зарегистрировать service worker, поэтому PWA не сможет установиться, а раздел историй не будет работать.

Нужен Node.js 18.17 или новее. Самый простой способ:

1. Откройте папку `islamic-pwa/backend` в терминале.
2. Скопируйте `.env.example` в `.env` и задайте длинный `ADMIN_TOKEN` (нужен только владельцу для модерации).
3. Выполните `npm start`.
4. Откройте [http://localhost:8080](http://localhost:8080).

Можно также дважды нажать [START-NUR.cmd](START-NUR.cmd): окно сервера должно остаться открытым, пока вы пользуетесь приложением.

Для установки откройте приложение именно через `localhost` или HTTPS. В Chrome/Edge выберите **Установить приложение** в меню браузера; в Safari на iPhone/iPad используйте **Поделиться → На экран «Домой»**. Кнопка «Установить приложение» внутри Nur даёт подходящие инструкции для текущего браузера.

## Истории и модерация

Пользовательская история сначала получает статус `pending` и не видна публично. Откройте [http://localhost:8080/moderator.html](http://localhost:8080/moderator.html), введите свой `ADMIN_TOKEN`, выберите заявку и нажмите «Опубликовать» или «Отклонить».

Токен не записывается в браузер и не передаётся в основное приложение. Он хранится только в `backend/.env`, который не должен попадать в Git, архивы или публичный хостинг.

## Что работает без внешнего API

- Счётчик, цели, зикры и история сохранений — в `localStorage` этого браузера.
- «Сотри и узнай» работает через Canvas с поддержкой мыши, касания и кнопки принудительного раскрытия.
- Справочный помощник работает локально и не делает вид, что выдаёт фетвы. В спорном или личном вопросе он направляет к знающему местному имаму.
- Звуки создаются браузером через Web Audio, а вибрация включается только на поддерживаемых устройствах и может быть отключена в настройках.

Аудио Корана загружается из публичных внешних источников, поэтому для него необходим интернет. Перед публичным запуском проверьте применимые права, доступность источников и релевантные нормы в целевых странах.

## Структура

```text
islamic-pwa/
├─ index.html                 # основное PWA
├─ moderator.html             # закрытая страница ручной модерации
├─ css/                       # мобильный дизайн и панель модерации
├─ js/                        # интерфейс, контент и модерация
├─ locales/                   # 12 словарей и поддержка RTL
├─ assets/                    # SVG и PNG иконки PWA
├─ manifest.webmanifest
├─ sw.js                      # офлайн-кэш оболочки, без кэша API
├─ START-NUR.cmd              # быстрый запуск на Windows
└─ backend/                   # Node.js сервер и закрытое хранилище историй
```

Для внешнего запуска разместите сервер за HTTPS reverse proxy. Не выставляйте административный маршрут в общий доступ без сильного `ADMIN_TOKEN` и дополнительной защиты доступа.
